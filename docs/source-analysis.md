# Аналіз `source_files/` — що там є і як використовувати

`source_files/` — **дані замовника з грифом ДСК**. Не комітити в git (додати в `.gitignore`), не
відправляти нікуди за межі машини/сервера, не цитувати великими шматками в логах. Використовуються як:
(1) джерело сід-даних довідників, (2) фікстури тестів імпорту, (3) еталони для золотих тестів
генерації документів, (4) архів для одноразового переносу. Тести, що читають `source_files/`,
мають пропускатися (skip), якщо каталогу нема.

## 1. `source_files/Дельта/` — старий облік (переважно синтетичний)

Дерево: корінь (УВ(с)) → `17 АК`, `20 АК`, `30 КМП`, `7 КШР`, `ОТУ «Одеса»` → підпапки частин;
`39 зрп`, `475 ошп`, `67 омбр` прямо під коренем. Порожні `Службові`.

- `ОблікФаховоїПідготовкиВЧ.xlsx` (51 файл, 534 рядки): аркуші `Записи` / `Довідник` / `Інструкція`.
  **Заголовки зсунуті**: колонка "Місце проведення" фактично містить **назву самої частини**, у
  "Примітка" — організатор (4 значення), "Організатор" і "Виконання" порожні. Частину визначати з
  шляху папки.
- `ОблікФаховоїПідготовкиАК.xlsx` (6 файлів, 91 рядок): + колонки "АК, ОТУ", "Військова частина".
  Кореневий файл — "ОК Південь (зведено)" з перемішаними колонками.
- **Дані тут переважно згенеровані випадково** (ВОС/спеціальність/ОВТ не узгоджені; жоден рядок АК-рівня
  не збігся з файлом відповідної ВЧ). Живі дані — тільки `20 АК/ОблікФаховоїПідготовкиАК.xlsx`
  (17 овмбр: неповні назви місць, обрізані спеціальності "посвідчення водія)", "(оператор)",
  `-----`, варіанти "УВ КУРСЬК"/'УВ "Курськ"', реквізити в примітці). **Для словника ВОС/ОВТ
  синтетичні пари НЕ використовувати.**
- `Довідник` (однаковий у всіх файлах): 208 місць навчання/частин, 226 спеціальностей, 202 ВОС,
  287 ОВТ — **придатний як сід списків значень** (але не зв'язків між ними).
- `20 АК/ІВСАК.xlsx` — укомплектованість груп інструкторів, проходять/пройшли курси (КІБР, КПК,
  Ком. відд., Фах) по місяцях. Дефекти: `160 омбр ()` без номера; А4007 записано і за 110 омбр, і за 44 омбр.
- `20 АК/АдаптаціяАК.xlsx`, `АдаптаціяВЧ.xlsx` — **поіменні** (ПІБ, звання, старший групи, накази).
  Людей не зберігаємо — брати тільки структуру й довідники: джерело надходження ("з нц (цпп)",
  "перепризначення"), причини незавершення (СЗЧ, лікування, смерть, пропуск, переведення, інше),
  результати вхідного контролю ТП / ВП (МБ) / ТМ (ПДгД) / ВТ.
- `ПотребаАК/ВЧ.xlsx`, `*-superset.xlsx`, `АдаптаціяАК.xlsx` у 17 АК/30 КМП/7 КШР/ОТУ — порожні заглушки.
- `ІНСТРУКЦІЯ … .docx` (45 однакових копій) = аркуш `Інструкція`: бізнес-правила (див. 03 §5).
- `7 КШР/92 ошбр/…(резервна копія не видаляти).xlsx` — ідентична копія.
