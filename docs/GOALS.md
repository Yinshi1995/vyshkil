# Цілі для автономного режиму

Цей файл читає кожна автономна сесія (tmux Remote Control і нічний раннер) ПЕРЕД початком
роботи — єдине джерело "що робити", не вигадувати задачі самому. Формат: чекбокс-список,
найважливіше зверху. Користувач редагує цей файл (з телефону через Remote Control або з
Windows), автономна сесія лише читає й відмічає виконане — не додає собі нові цілі.

- [ ] (порожньо — додай першу ціль тут; дивись `docs/spec/06-roadmap.md` за орієнтиром
  наступного кроку, якщо немає конкретнішого завдання)

## Правила для автономної сесії

- Одна ціль за раз, зверху вниз. Позначити `[x]` і додати дату лише ПІСЛЯ зеленого
  `cargo test`/e2e там, де це застосовно (ніяких "зроблено на слово").
- Заблокований на чомусь, що потребує рішення користувача (дані, credential, архітектурний
  вибір поза `docs/spec`) → записати в `docs/QUESTIONS.md`, не зупиняти всю сесію — перейти до
  наступної ціли або до дрібного рефакторингу/тестів, якщо черга цілей порожня.
- Жодного `git push` — заблоковано `.claude/settings.json` і так (deny-правило), автономна
  сесія лише комітить локально.
