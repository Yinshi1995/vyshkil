# Vyshkil — специфікація

Застосунок обліку заходів підготовки військових частин УВ(с) "Південь":
збір даних (форма / таблиця / офіційне звернення), нормалізація, звірка між рівнями
підпорядкування, виявлення розбіжностей і генерація звітних документів.

Цей каталог — **джерело істини про домен**. Код, міграції і рішення мають з ним узгоджуватись.
Якщо реалізація вимагає відступити від специфікації — спершу онови специфікацію
(і запиши рішення в `.claude/decisions/`), потім пиши код.

## Глосарій

- **УВ(с) "Південь"** = **ОК "Південь"** = **Угруповання військ (сил) "Південь"** — синоніми, один
  і той самий верхній орган у нашій системі (корінь нашого дерева, але не корінь усього світу:
  вище може бути КСВ тощо).
- **ЧБП** — частини безпосереднього підпорядкування УВ(с) "Південь". У звітах стоїть поруч з АК/ОТУ
  як окрема група, але це **не орган управління**, а віртуальна група "підпорядковані напряму нам".
- **АК, ОТУ, КМП, КШР** — органи управління (армійський корпус, оперативно-тактичне угруповання,
  корпус морської піхоти, корпус штурмових військ тощо).
- **ВЧ** — військова частина. Має умовний номер (А####, Т####, "в/ч ####" для НГУ) і назву (скорочену: "128 огшбр").
- **Штатне підпорядкування** vs **оперативне підпорядкування** — дві різні осі підпорядкування,
  обидві змінюються в часі (див. 01).
- **Види підготовки**: БЗВП (базова загальновійськова), фахова (здобуття ВОС), адаптація
  (допідготовка в частині після НЦ або перепризначення). Всередині фахової — напрямки:
  командири відділень (КВід), інструктори (КІБР, КІПР, КПК, СККВ…), БпС (безпілотні системи).
- **ВОС** — військово-облікова спеціальність (код, напр. 218). У розмовній мові — **фах**.
  Потрапляє у військовий квиток наказом після успішного навчання.
- **ОВТ** — озброєння та військова техніка (тип дрона, радіостанції, танка…). Часто саме за
  ОВТ люди описують, чого вчилися ("Вампір"), а система має підказати ВОС (218).
- **НЦ / ЦПП / НБ / школа** — місце навчання: зазвичай теж ВЧ з номером, інколи навчальний
  заклад без номера, ТОВ/ГО, іноземна держава.
- **Подання** — одна порція даних від когось: форма, завантажена таблиця або офіційне звернення.
- **Розбіжність** — два подання кажуть різне про одне й те саме.
