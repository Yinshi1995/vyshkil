# 02. Форми введення

Мета: людина, яка щодня вносить десятки рядків, робить це **без миші**, швидше ніж в Excel,
і фізично не може внести сміття — система підказує правильне значення раніше, ніж людина
закінчить друкувати.

## 1. Основна форма — табличний редактор рядків

Замість "одна група — одна сторінка" — **сітка** (як Excel), кожен рядок = одна група на навчанні.

**Військова частина-відправник — ОДИН раз на все подання, не колонка рядка** (feedback
користувача, 2026-09-30 — `.claude/decisions/sender-org-once-per-submission.md`): обирається в
тулбарі сторінки, поруч зі "Станом на", за замовчуванням — організація актора; для корпусу —
вибір з піддерева. Хтось хоче внести за кілька частин одразу — це ОКРЕМІ подання (нове
відкриття форми), не перемикання посеред одного. Обраний вибір проставляється в кожен рядок
подання автоматично (не питає повторно).

Колонки сітки (порядок = порядок Tab):

1. Вид підготовки (БЗВП / фахова / адаптація / стажування) + програма для БЗВП
2. ВОС / посада / курс — **одне поле з розумним пошуком** (див. §3)
3. ОВТ
4. Місце проведення (частина + населений пункт)
5. Термін з / по
6. Кількість (план) → Прибуло → Навчаються (для нової групи часто рівні — див. автозаповнення)
7. Розподіл за підрозділами (розкривний підрядок, опційно, в "розгорнути рядок")
8. Організатор, підстава (№, дата розпорядження) — в "розгорнути рядок"
9. Примітка — в "розгорнути рядок"

Сітка віртуалізована (рендерити тільки видимі рядки): записів у частини — сотні.

**Виняток — імпорт файлом на `/import` (Ivs/Архів ВЧ)**: там рядки резолвлять частину З ФАЙЛУ
(потенційно різну на кожен рядок, бо джерело — зведений документ по кількох частинах відразу) —
toolbar-селектор тут не підходить; нерозпізнана частина позначається тим самим індикатором
помилки рядка, що й решта, виправляється через "розгорнути рядок".

## 2. Клавіатура

| Клавіша | Дія |
|---|---|
| `Tab` / `Shift+Tab` | наступне / попереднє поле; з останнього поля рядка — у перше поле наступного рядка (створює новий, якщо це кінець) |
| `Enter` | підтвердити вибір у випадайці і перейти до наступного поля (як Tab); в останньому полі — новий рядок |
| `↑ ↓` | у відкритій випадайці — пересування; у закритій — перейти на рядок вище/нижче в тій самій колонці |
| `Alt+↓` | відкрити підказки поточного поля |
| `Esc` | закрити випадайку; вдруге — скасувати редагування клітинки |
| `Ctrl+D` | скопіювати значення з клітинки вище (як в Excel) |
| `Ctrl+Shift+D` | дублювати весь рядок нижче (типово: ті самі частина/місце/терміни, інший ВОС) |
| `Ctrl+Enter` | зберегти всі зміни |
| `Ctrl+Z` / `Ctrl+Shift+Z` | undo / redo в межах сесії редагування |
| `Ctrl+Delete` | видалити рядок (з підтвердженням) |
| `F2` | редагувати клітинку, не стираючи вміст |
| `?` або `F1` | накладка-шпаргалка з усіма гарячими клавішами |
| `Ctrl+K` | командна палітра: "перейти до частини…", "імпортувати таблицю…", "згенерувати звіт…" |

Шпаргалка показується автоматично при першому відкритті; внизу сітки завжди видно рядок-підказку
з 3–4 найкориснішими клавішами для **поточного** поля.

## 3. Підказки й автокомпліт

- Пошук **нечіткий**: по `alias.norm` + `pg_trgm`, стійкий до опечаток, розкладки (набрав латиницею
  замість кирилиці — все одно знайде), порядку слів. Результати ранжуються: точний збіг синоніма
  → частота використання цією організацією → схожість.
- Поле частини/місця розуміє **будь-що**: номер ("4896", "А4896", "a4896"), назву ("152 нц", "152НЦ"),
  синонім ("Польша"). У випадайці показується канонічна форма `152 нц (А4896), м. Верхньодніпровськ`.
- **Поле ВОС розуміє ОВТ і посаду.** Набрав "вамп" → підказка:
  `ВОС 218 — зовнішній пілот (оператор) БпЛА  ·  бо "Vampire" → 218`. Вибір заповнює ВОС,
  пропонує посаду і ставить "Vampire" в ОВТ. Набрав "mavic" → 217; "fpv" → 219; "нрк" → 129.
  Джерело — `equipment_vos` + `vos_position` (див. 01). Пояснення "бо …" обов'язкове:
  людина має розуміти, чому система пропонує саме цей фах.
- Якщо введене значення не знайдено — не блокувати: запропонувати "створити нове значення"
  (потрапляє адміну на підтвердження) і зберегти як `learned`-синонім після вибору.
- Інструкторські курси (КІБР, КІПР…) — **без ВОС**; поле ВОС для них ховається.

## 4. Розумне автозаповнення

- Новий рядок успадковує частину, вид, місце, терміни з попереднього рядка (підсвічено сірим,
  `Tab` приймає, будь-який друк замінює).
- "Прибуло" і "Навчаються" за замовчуванням = "План"; змінюються окремо.
- Місце + ВОС → пропонується типова тривалість курсу за історією (термін "по" підставляється
  автоматично, редагується).
- Дати вводяться як завгодно: `18.08`, `18.08.26`, `18.08.2026`, `18.08-09.10` (діапазон в одне
  поле "з" — автоматично розкладається на "з" і "по"), `2026-08-18`. Рік без явного — з контексту
  (див. 03 §4).

## 5. Валідація в реальному часі

Та сама функція валідації, що й для імпорту (спільний код у `app`, працює в WASM без запиту до
сервера) — див. 03. У формі:
- помилка — червона рамка клітинки + текст під сіткою "Рядок 4, «Термін по»: 31.09 — такої дати нема";
- попередження (не блокує збереження) — жовта рамка, напр. "тривалість 2 дні — нетипово коротко";
- `Ctrl+Enter` при наявності помилок фокусує першу помилкову клітинку і не зберігає.

## 6. Чернетки

Незбережені зміни зберігаються як `submission(status='draft')` на сервері кожні кілька секунд —
закрита вкладка або обрив VPN не губить роботу.

## 7. Вставка з Excel

`Ctrl+V` у сітку блоку клітинок з Excel **дозволений** (на відміну від старої інструкції "Дельти") —
але вставлене проходить той самий шлях, що й імпорт: розпізнавання → валідація → підсвічування.

## 8. Доступність і вигляд

Висока контрастність, великий шрифт у клітинках, робота на ноутбуці 1366×768 без горизонтального
скролу для основних колонок. Кольори інтерфейсу узгодити зі стилем презентацій
(темно-оливковий + помаранчевий акцент, див. 05), але без шкоди читабельності таблиць.
