# opt-level=z + lto + panic=abort + strip у релізі

**Чому:** цільовий сервер слабкий (обмежені RAM/CPU/диск). Свідомо міняємо пікову швидкодію
і час збірки на менший бінарник і менший RSS: `opt-level = "z"` оптимізує під розмір,
`lto = true` вирізає мертвий код між крейтами, `codegen-units = 1` дає компілятору повну
картину програми, `panic = "abort"` прибирає таблиці unwind-лендінгів, `strip = true`
знімає debug-символи.

**Де:** кореневий `Cargo.toml`, `[profile.release]` — застосовується до всіх крейтів воркспейсу
(включно з `migration`-бінарником; для нього це теж прийнятно).

**Ціна:** значно довший `cargo build --release` (LTO + 1 codegen-unit серіалізують оптимізацію).
