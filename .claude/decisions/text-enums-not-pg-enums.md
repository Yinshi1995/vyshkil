# Enum-подібні значення — довідкові таблиці або text+CHECK, не Postgres ENUM

**Чому:** перелік ВОС, статусів, причин вибуття тощо регулярно поповнюється (замовник вносить
офіційний перелік ВОС пізніше; причини вибуття мають "інше + текст"). Додавання значення до
Postgres `ENUM` вимагає міграції типу (`ALTER TYPE ... ADD VALUE`, не транзакційно в старих версіях,
незручно для довідників, що ростуть за життя проєкту).

**Як застосовувати:** для закритих і рідко змінюваних наборів — `text` + `CHECK (value IN (...))`;
для наборів, що ростуть від користувацьких дій (ВОС, синоніми, причини вибуття з довільним текстом)
— окрема довідкова таблиця з FK. Правило зафіксовано і в `migration/CLAUDE.md`.
