# Візуальний стиль UI: живий сайт striy.pp.ua — авторитетне джерело, не документи

**Статус (2026-09-29):** палітра/шрифти тут лишаються авторитетними — нічого не змінилось по
суті. СПОСІБ реалізації (як ці значення потрапляють у CSS) замінено — див.
`docs/spec/08-style-system.md` і `.claude/decisions/style-system-architecture.md` (крейт `style`,
токени як Rust-дані, `cx!`-проц-макро замість BEM-класів у `app/style/main.css`).

**Історія:** спроба 1 помилково взяла палітру генерованих документів (`05-documents.md`).
Спроба 2 взяла кольори з пікселів `Напрацювання ВВД.pptx` (близько, але приблизно). Користувач
показав живий продакшн-сайт **striy.pp.ua** ("Центр підготовки УВ(с) «Південь»" — та сама
організація, що й Taktoblik) як точний еталон — виміряно через Playwright `getComputedStyle`,
не на око.

## Виміряні значення (авторитетні)

| Токен | Значення | Де виміряно |
|---|---|---|
| Фон сторінки | `#0D0F0A` | `getComputedStyle(body).backgroundColor` |
| Основний текст (заголовки) | `#E8E4D8` | `getComputedStyle(h1).color` |
| Акцент (золото) | `#C9A84C` | межа іконки-квадрата (`border`) |
| Шрифт заголовків/навігації | `Oswald` (700, uppercase, `letter-spacing: 4px` на h1) | `getComputedStyle(h1).fontFamily` |
| Шрифт тіла | `Roboto` | `getComputedStyle(body).fontFamily` |

Другорядні тони (панель/секондарі/muted) виміряти напряму не вдалось (селектори не влучили в
класи сайту) — підібрані вручну як гармонійне продовження виміряної пари фон/текст.

## Композиційні патерни (візуально з живого сайту)

- Картка: фото зверху (grayscale/duotone) → квадратна іконка з 2px золотою рамкою → жирний
  uppercase заголовок (Oswald) → опис (Roboto) → золотий лінк "ДЕТАЛЬНІШЕ →".
- Секція: маленький eyebrow-лейбл ("РОЗДІЛ 01") з тонкими лініями обабіч, під ним великий
  центрований заголовок, під ним центрований підзаголовок.
- Кнопки: скошений правий край (`clip-path` паралелограм) — суцільна золота (primary) і
  контурна (secondary).
- Навігація: uppercase, letter-spacing, активний пункт підкреслений золотим.

## Рішення

`app/style/main.css` — темна база `#0D0F0A`, текст `#E8E4D8`, єдиний акцент `#C9A84C` (не
мультиколірна система категорій — на живому сайті один акцент, не декілька). Шрифти Oswald +
Roboto **самохостяться** (`app/assets/fonts/*.woff2`, `assets-dir` в кореневому `Cargo.toml`) —
жодного виклику на fonts.googleapis.com в рантаймі (CLAUDE.md: "шрифти — локально").

Компонентна мова: `.icon-box` (квадрат, золота рамка, іконка-SVG всередині), `.card`
(icon+title+desc), `.btn`/`.btn--outline` (скошений край через `clip-path`), `.eyebrow`
(секційний лейбл з лініями).

**Таблиці й форми лишаються без декору** (без фото, без скосів) — `02-input-forms-ux.md` §8
явно вимагає "без шкоди читабельності таблиць"; стиль-мова застосовується до навігації/карток/
кнопок, не до рядків даних.

**Генератори документів (Етап 7+) лишаються на палітрі `05-documents.md`** — це окремий,
уже підтверджений (`Доповідь №1.pptx`) стиль, не змінювати під цей.
