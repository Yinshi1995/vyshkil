# Два окремих джерела кольору: UI застосунку ≠ генеровані документи

**Помилка першої спроби:** взяв палітру `docs/spec/05-documents.md` (панелі `#38331F`, найтемніше
`#0E0C08`, текст `#F7F5F0`/`#D2CCBC`/`#A8A08A`) і застосував її до UI застосунку. Це палітра для
**генерованих документів** (D1–D6) — підтверджено: `Доповідь №1.pptx` (переданий користувачем
еталон саме генерованого звіту) містить **точно** ці коди (перевірено `grep srgbClr` по XML
слайдів: F39200×159, F7F5F0×144, D2CCBC×103, 38331F×29, A8A08A×17, 0E0C08×1 — збіг 1:1 зі spec).

Для самого UI застосунку користувач окремо передав `Напрацювання ВВД.pptx` — інший, теплiший і
багатший набір (той самий `grep` по цьому файлу):

| Роль | Hex | Використань |
|---|---|---|
| Акцент (спільний з документами — єдиний бренд) | `#F39200` | 127 |
| Основний текст | `#F5F2EC` | 40 |
| Другорядний текст | `#C7C1B0` | 43 |
| Приглушений текст | `#9C947F` | 47 |
| Панель (світліша) | `#453F2E` | 35 |
| Панель (темніша) | `#393529` / `#333026` | 9 / 4 |
| Найтемніше тло | `#302D24` (не `#0E0C08` — той темніший, для документів) | 19 |
| Акцент-категорія: блакитний | `#8FAEC9` | 31 |
| Акцент-категорія: золотий | `#D9C08A` | 28 |
| Акцент-категорія: шавлієвий | `#9DB08C` | 20 |
| Акцент-категорія: теракотовий | `#C98F6E` | 8 |
| Темніший помаранч (hover/naголос) | `#855000` | 5 |

Композиція референсу (слайд "ГНСС в умовах 433 бригади"): іконка (свій колір на категорію) +
жирний заголовок + опис-абзац, три такі картки в ряд, під ними рядок міні-статів
("433 бійці", "без GNSS", "?10 м", "Mavic/Autel"). Це патерн "icon + text rows" — картка на
категорію з характерним кольором іконки, не суцільний один акцент на все.

**Рішення:** `app/style/main.css` використовує палітру UI-референсу (таблиця вище), не
`05-documents.md`. Категорійні кольори (блакитний/золотий/шавлієвий/теракотовий) — для іконок/
бейджів за типом сутності (напр. `training_kind`: БЗВП/фахова/адаптація/стажування), не для тексту
й не для фону панелей. `#F39200` лишається єдиним акцентом і в документах, і в UI — це те, що
візуально єднає бренд.

**Де:** `app/style/main.css`. Генератори документів (Етап 7+) лишаються на палітрі `05-documents.md`
— не міняти їх під цю.
