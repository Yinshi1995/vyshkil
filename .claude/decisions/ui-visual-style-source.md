# Джерело візуального стилю UI — той самий, що й для документів (05)

Користувач передав `Напрацювання ВВД.pptx` (реальна презентація в стилі, спорідненому з
`docs/templates/presentation-style.pptx`) як референс того, який вигляд має мати сам застосунок
(не тільки згенеровані документи). Це узгоджується з `docs/spec/02-input-forms-ux.md` §8:
"Кольори інтерфейсу узгодити зі стилем презентацій (темно-оливковий + помаранчевий акцент, див. 05),
але без шкоди читабельності таблиць" — тобто вимога вже була в специфікації, референс лише уточнює
конкретний відтінок/фактуру (темна оливково-чорна фото-текстура з градієнтом, плоскі кольорові
іконки без обвідки).

**Рішення:** глобальна CSS-палітра застосунку бере точні hex-коди з `05-documents.md`
(панелі `#38331F`, найтемніше `#0E0C08`, акцент `#F39200`, текст `#F7F5F0`/`#D2CCBC`/`#A8A08A`) —
не з пікселів референсу (той — лише підтвердження напрямку, конкретні коди вже зафіксовані в spec).
Таблиці й форми — без фото-текстур (це UI для щоденної роботи, не презентація): суцільний темний
фон, панелі-картки, помаранчевий акцент лише для заголовків/чисел/фокусу — "без шкоди читабельності".

**Де:** `app/style/main.scss` (CSS custom properties), підключено через
`[[workspace.metadata.leptos]] style-file` у кореневому `Cargo.toml`.
