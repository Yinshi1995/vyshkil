# Одна функція нормалізації синонімів — в `app`, спільна для SSR і WASM

**Чому:** валідація в реальному часі у формі введення (`docs/spec/02-input-forms-ux.md` §5) має
працювати в браузері без запиту до сервера — та сама функція, що й для імпорту
(`03-import-validation.md`). Дві окремі реалізації (сервер/клієнт) неминуче розійдуться на
реальних варіаціях написання ("241 обр ТрО" vs "241 обртро", "А1556" vs "a1556").

**Як застосовувати:** нормалізація (нижній регістр, латинські↔кириличні двійники, прибрати лапки/
дужки, уніфікувати дефіс/тире) — чиста функція в `app` без `sea-orm`/`tokio` (`app/CLAUDE.md`).
Порівняння — по `alias.norm`; нечіткий пошук для підказок — `pg_trgm similarity` (лише на сервері,
через server function, бо це запит до БД). Учений синонім (`alias.source='learned'`) створюється,
коли користувач вручну підтверджує відповідність для невідомого сирого значення.
